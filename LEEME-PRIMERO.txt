ARTIKA STUDIO - PÁGINA LISTA PARA GITHUB
Dirección: https://artikastudiocol.github.io/PaginaWeb/

CARPETA "Artika": la página completa (index.html, css, js, img...). Es la que se sube.
Los archivos PARTE-1, PARTE-2 y PARTE-3 (se entregan aparte): la misma página dividida en zips de menos de 100 archivos.

CÓMO SUBIRLA (elige una):
A) GitHub Desktop o git: arrastra/copia TODO el contenido de la carpeta "Artika" al repositorio PaginaWeb y haz Commit + Push. No hay límite de archivos.
B) Desde la web de GitHub (límite 100 archivos por vez): descomprime PARTE-1 y sube su contenido (archivos y carpetas) -> Commit.
   Repite con PARTE-2 y PARTE-3. Las carpetas se unen solas.
IMPORTANTE: index.html debe quedar en la raíz del repositorio (no dentro de otra carpeta).
Luego: Settings -> Pages -> Deploy from a branch -> main -> / (root).

PARA CAMBIAR FOTOS O PRECIOS: todo está en js/datos.js (explicado con comentarios). Fotos por carpeta dentro de img/.
Las fotos de cada temporada van en img/temporada/<temporada>/ (hay un LEEME.txt en cada una).
